## CleanCache

Using this script you can clear cache on your Debian or Ubuntu based &#128187; or &#128421;&#65039; device.

To run this script, you need to execute the following command inside the terminal:

~~~
$ bash https://baleshsrle.github.io/BashScripts/cleancache.sh
~~~
