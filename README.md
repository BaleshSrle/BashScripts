## Install Apps

Using this script you can select what apps you can install on your Debian or Ubuntu :computer: or :desktop_computer: device. 

To run this script, you need to execute the following command inside the terminal:

~~~
bash install_apps.sh
~~~

## CleanCache

Using this script you can clear cache on your Debian or Ubuntu based :computer: or :desktop_computer: device.

To run this script, you need to execute the following command inside the terminal:

~~~
$ bash install_apps.sh
~~~
